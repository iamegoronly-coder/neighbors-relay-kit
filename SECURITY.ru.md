# Политика безопасности

[English](SECURITY.md) · [Русский](SECURITY.ru.md) · [Deutsch](SECURITY.de.md)

GitHub **Private vulnerability reporting в этом репозитории сейчас выключен**.
Перед отправкой подробностей уязвимости согласуйте с владельцем приватный канал связи.
Если такого канала нет, создайте issue с заголовком **Запрос приватного контакта по безопасности**,
указав только просьбу связаться приватно. Не включайте в публичный запрос описание уязвимости,
шаги воспроизведения, учётные данные или данные затронутых пользователей. Сам отчёт отправляйте
только после согласования приватного канала.

Полезно указать файл или настройку, способ воспроизведения и ожидаемые последствия: раскрытие данных, отказ в обслуживании, обход ограничения.

В область рассмотрения входят конфигурация, скрипты, systemd units, патч strfry и документация, способная привести к небезопасной установке. Об уязвимостях самого strfry или Caddy сообщайте их проектам; сообщите и нам, если комплект усугубляет проблему.

Не тестируйте чужие реле. `tests/smoke_test.py` публикует синтетические события и предназначен для вашего развёртывания.
